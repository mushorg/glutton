# `nettcp` decoded data

Transport: TCP (default rule: tcp/4025 and tcp/4026, Visual Studio remote debugger `msvsmon`, and tcp/9401, WCF NetTcp clients that upgrade to TLS; the handler does not depend on the port, the Via is read from the preamble). Shared encodings and frame fields are described in [Logging and producers](../logging.md#decoded-data).

**`decoded`:** Array of per-record frames: `direction`, `command`, `path`, `status`, `version`, `mode`, `content_type`, `fault`, `server_name`, `tls`, `payload`, `truncated`

Each frame is one .NET Message Framing ([MS-NMF]) record, the framing used by WCF `NetTcpBinding`. `payload` is the raw record. `command` is the record name (`Version`, `Mode`, `Via`, `KnownEncoding`, `ExtensibleEncoding`, `UpgradeRequest`, `UpgradeResponse`, `PreambleEnd`, `SizedEnvelope`, `UnsizedEnvelope`, `End`, `Fault`, `PreambleAck`), `tls` for the TLS upgrade handshake, or `0x..` for an undefined record type. `path` is the Via URI. `version` is `major.minor`. `mode` is `singleton-unsized`, `duplex`, `simplex` or `singleton-sized`. `content_type` is the known encoding's content type, the extensible encoding string, or the upgrade protocol of an `UpgradeRequest`. `fault` is the full fault string, and `status` on a write frame is its short name (`UnsupportedVersion`, `UnsupportedMode`, `ContentTypeInvalid`, `UpgradeInvalid`). `truncated` marks a record cut by the 64 KiB cap or by the client disconnecting mid-record.

Replies: `PreambleEnd` gets `PreambleAck`, and `End` gets `End` (then close). An `UpgradeRequest` for `application/ssl-tls` gets an `UpgradeResponse` (`0a`), then the honeypot runs a TLS server handshake with the shared self-signed certificate. That handshake is recorded as a read frame with `command` `tls`, the raw ClientHello in `payload` and the SNI in `server_name`. Records read and written after it are decrypted and carry `tls: true`, and the event's top-level `tls` field (JA3/JA4, version, cipher) is set. An unsupported version, mode or encoding, any other `UpgradeRequest` (SSPI `application/negotiate` is not emulated), and a second upgrade inside TLS get a `Fault` record and the session closes. Envelopes are recorded without a reply.

[MS-NMF]: https://learn.microsoft.com/en-us/openspecs/windows_protocols/ms-nmf/
